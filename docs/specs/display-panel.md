# Display panel

Files: `sway/.config/sway/panels/display.qml` (Quickshell, drawing only), `sway/.config/sway/panels/display/ctl` (every read and write: state, brightness, scale, laptop screen, text size), `sway/.config/sway/panels/display/toggle` (run by a click on the waybar monitor icon and by the menu entry Setup > Display), `sway/.config/sway/panels/display/refresh` (Fn brightness keys and the wheel on the bar icon), `sway/.config/sway/panels/display/reinit` (after resume, through `bin/idle`).

## Purpose

The panel sets brightness, scale and text size per monitor, and turns the laptop screen off while another monitor is connected. The built-in panel's brightness goes through the kernel backlight and an external monitor's through DDC/CI. After a resume, external monitors get a new modeset, because with the NVIDIA driver they can stay black.

## Acceptance criteria

1. The panel file parses, every type, property and import resolves against Qt and Quickshell, and Quickshell loads it in a headless Sway. Test: `tests/static.sh: qmllint`, `tests/static.sh: panels-load`
2. Esc closes the panel. Test: manual
3. The panel opens on the focused monitor. With more than one monitor, the chevrons and Left and Right switch between them, and the panel reads the brightness of the one shown. Test: `tests/unit/sway/.config/sway/panels/display/ctl.bats: "state: outputs with the internal flag, text size from alacritty.toml [font]"`, manual
4. The brightness reads from the backlight on the built-in panel and over DDC/CI on an external monitor, and shows "unavailable" when the monitor has no DDC/CI. The DDC bus is detected once per monitor and cached for the session, and a stale cache is dropped so the next read detects again. Test: `tests/unit/sway/.config/sway/panels/display/ctl.bats: "brightness get, built-in panel: backlight percent"`, `tests/unit/sway/.config/sway/panels/display/ctl.bats: "brightness get, external: DDC bus detected once, then cached"`, `tests/unit/sway/.config/sway/panels/display/ctl.bats: "brightness get, stale cache: dropped, unavailable, next call detects again"`, `tests/unit/sway/.config/sway/panels/display/ctl.bats: "brightness get, monitor without DDC: unavailable"`
5. Dragging the slider, the wheel over it, and Up and Down change the brightness between 1% and 100%. Only the last value of a drag or a wheel burst is written. On an external monitor the percentage is scaled to the monitor's own maximum. Test: `tests/unit/sway/.config/sway/panels/display/ctl.bats: "brightness set: backlight for the panel, VCP 10 scaled to the monitor's max for DDC"`, manual
6. A brightness change made outside the panel (Fn keys, wheel on the bar icon) shows in an open panel, unless a change from the panel is still being written. With the panel closed, nothing runs. Test: `tests/unit/sway/.config/sway/panels/display/refresh.bats: "panel closed: quickshell never called, exit 0"`, `tests/unit/sway/.config/sway/panels/display/refresh.bats: "panel open: ipc refresh sent to the display panel"`, manual
7. The scale chips (1x, 1.25x, 1.6x, 2x) set the scale of the monitor shown until Sway restarts, and the active one is highlighted. Test: `tests/unit/sway/.config/sway/panels/display/ctl.bats: "scale and toggle: one swaymsg output command"`, manual
8. The laptop screen section shows only while another monitor is connected, so the laptop never ends with no screen on, and turns the built-in panel off and on. Test: `tests/unit/sway/.config/sway/panels/display/ctl.bats: "scale and toggle: one swaymsg output command"`, manual
9. The text size chips (9 to 20) set the terminal font size in the `[font]` section of `alacritty.toml` and the GTK text scaling factor, where 12 is factor 1.0. A size outside 9 to 20 or not a number changes nothing. Test: `tests/unit/sway/.config/sway/panels/display/ctl.bats: "text: size inside [font] only, GTK factor quantized to whole points"`, `tests/unit/sway/.config/sway/panels/display/ctl.bats: "text: 12 = factor 1.0, the anchor"`, `tests/unit/sway/.config/sway/panels/display/ctl.bats: "text: outside 9..20 or not a number: exit 2, file untouched"`, `tests/unit/sway/.config/sway/panels/display/ctl.bats: "state: no size in [font] means 12"`
10. `ctl` validates output names and numbers before they reach `swaymsg` or arithmetic, and a call with a missing argument prints the usage and exits 2. Test: `tests/unit/sway/.config/sway/panels/display/ctl.bats: "output names and numbers validated before they reach swaymsg or arithmetic"`, `tests/unit/sway/.config/sway/panels/display/ctl.bats: "no argument: usage, exit 2"`, `tests/unit/sway/.config/sway/panels/display/ctl.bats: "brightness without get or set: usage, exit 2"`
11. After a resume, every active external monitor is disabled and enabled again, and the built-in panel and inactive outputs are left alone. Test: `tests/unit/sway/.config/sway/panels/display/reinit.bats: "active external outputs: disable then enable each, built-in panel and inactive ones untouched"`, `tests/unit/sway/.config/sway/panels/display/reinit.bats: "only the built-in panel: no output command"`, manual
