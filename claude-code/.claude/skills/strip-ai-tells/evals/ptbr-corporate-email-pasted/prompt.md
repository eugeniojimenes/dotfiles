Olá, time!

O novo sistema desempenha um papel crucial na construção de uma cultura de transparência, eficiência e confiança, potencializando a experiência de todos os colaboradores.

É importante destacar que o treinamento será realizado no dia 28 de novembro, às 15h, via Teams.
